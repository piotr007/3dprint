Key decisions already agreed:
- Monolith Laravel app, no separate API
- Filament as CMS/admin
- Trix for WYSIWYG
- GLightbox for gallery lightbox
- Local storage for files, future S3 migration prepared
- No categories/tags in MVP
- MVP language: English only
- Single admin account at start
- Image processing strategy:
  - keep only derived large + thumb
  - no original file stored
  - WebP output
  - large max 1200x900
  - thumb square 300x300
